# Spain-Living-Costs
Data analytics capstone project analyzing the cost of living in Spain.


### Week 2 - September 8-14
This week, I focused on setting up my capstone project and planning my approach. I finalized my project idea, which is to create an interactive data-driven recommendation model that compares cities in Spain based on affordability, employment opportunities, and quality of life.

I completed y project proposal and organized my GitHub repository. 
I also began researching potential data sources for my project. My main data source will be the Spanish National Statistics Institute (INE) Urban Indicators. This includes information such as income, rent, housing prices, employment, unemployment, population, transportation, tourism, and crime. I also plan to use the INE Household Budget Survey as a secondary source to understand household spending patterns in Spain.

### Week 3 - September 15-21

This week, I focused on collecting and organizing the data for my project. I downloaded seven INE datasets covering economic, social, transportation, tourism, education, land use, and demographic information and added them to my GitHub repository. I also reviewed the variables and began narrowing them down into my three main categories: affordability, employment, and quality of life. Since some variables have missing years, I decided to use the available data across multiple years to create representative city-level values rather than focusing on changes over time. Next week, I plan to begin cleaning the datasets and preparing them for analysis.
